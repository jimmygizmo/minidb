

Use Pyenv Virtualenv to create a virtual environment named ve.minidb

The .python-version file in this project has this VE name 've.minidb' in it so this will cause Pyenv to automatically
activate this VE when inside any directory under the directory containing the .python-version file.
I have found this to be the best way to handle Python virtual environments and Python version matching.

I used Python 3.12.4 so my Pyenv command was:

> pyenv virtualenv 3.12.4 ve.minidb

Then your prompt should look similar to this when inside the project:

(ve.minidb) username@hostname:~/repos/minidb$


------------------------------------------------------------------------------------

Always update setuptools and pip:

> pip install --upgrade setuptools

> pip install --upgrade pip


For any project that has a chance of needing to install platform-native builds for any Python libraries, I go ahead
and install and upgrade wheel, so we now have all tools for library installs and upgrades, themselves fully upgraded.
